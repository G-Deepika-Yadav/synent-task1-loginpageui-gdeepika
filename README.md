# Login Page UI

A clean and modern Login Page UI built using HTML and CSS.

## 📌 Objective

Design a simple login interface with:

- Email field
- Password field
- Login button
- Forgot Password text

---

## 🚀 Technologies Used

- HTML5
- CSS3

---

## 📂 Project Structure

```bash
login-ui/
│
├── index.html
├── style.css
└── README.md
```

---

## 🎨 Features

- Modern UI Design
- Centered Login Form
- Responsive Layout
- Hover Effect on Button
- Clean and Simple Interface

---

## 🛠️ How to Run the Project

1. Download or clone the repository

```bash
git clone <your-repository-link>
```

2. Open the project folder

3. Open `index.html` in your browser

---

## 📸 Output

The page contains:

- Email input field
- Password input field
- Forgot Password text
- Login button

with a modern aligned UI.
